## Overview

**PropertyBhandar** is a comprehensive property management application designed to simplify the buying, selling, and renting process while providing developers with a robust framework for building and maintaining the app.

### Why PropertyBhandar?

This project aims to enhance user experience and operational efficiency in real estate transactions.  
The core features include:

- 🔧 **Modular Architecture**: Streamlined project structure for easy maintenance and scalability.
- 🔗 **Robust Dependency Management**: Utilizes Gradle for efficient handling of libraries and plugins.
- 👥 **User-Friendly Interfaces**: Multiple activities and fragments designed for seamless user interactions.
- 📊 **Real-Time Data Handling**: Dynamic updates for property listings and user interactions.
- 💰 **Financial Tools Integration**: EMI calculator and budget planner for informed decision-making.
- ✅ **Comprehensive Testing Framework**: Ensures reliability and performance through unit and instrumented tests.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: Kotlin  
- **Package Manager**: Gradle

---

### Installation

Build PropertyBhandar from the source and install dependencies:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mayurndhome/PropertyBhandar
   ```

2. **Navigate to the project directory**:
   ```bash
   cd PropertyBhandar
   ```

3. **Install the dependencies**:

   Using **gradle**:
   ```bash
   gradle build
   ```

---

### Usage

Run the project with:

Using **gradle**:
```bash
gradle run
```

---

### Testing

**PropertyBhandar** uses the **test_framework** test framework. Run the test suite with:

Using **gradle**:
```bash
gradle test
```
